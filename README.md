# Flappy Bird - DQN Agent

A Deep Q-Network (DQN) agent trained to play Flappy Bird using PyTorch and Pygame.

## Usage

```bash
# Train (1000 episodes) then play
uv run main.py

# Play with trained model only
uv run main.py --play
```

## Sprites

Visual assets from [samuelcust/flappy-bird-assets](https://github.com/samuelcust/flappy-bird-assets) are included under `sprites_repo/`.

## Requirements

- Python 3.10+
- PyTorch
- Pygame
- NumPy
